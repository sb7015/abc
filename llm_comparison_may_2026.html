What each benchmark actually tests

🐛SWE-bench Verified

Can the AI fix real bugs in real GitHub projects? 87% means it correctly fixed 87 out of 100 actual production bugs.

⚙️SWE-bench Pro

Harder version of the bug-fixing test. Multiple programming languages, stricter rules, less chance of cheating from training data.

🧪GPQA Diamond

PhD-level questions in physics, chemistry, and biology. Tests deep scientific reasoning that can't be Googled in seconds.

🌐BrowseComp

Can the AI use a web browser to research a question and return the correct answer? Like a research assistant.

⌨️Terminal-Bench 2.0

Can the AI use a Linux command line to complete tasks? Like a junior dev working in a terminal.

🖥️OSWorld

Can the AI control a real desktop computer? Mouse, keyboard, multiple apps, full screens. Hardest agentic test today.

🔌MCP-Atlas

Can the AI call external tools and APIs in the right order? Critical for agentic systems and tool orchestration.

📚Context window

How much text the AI can read at once. 1M tokens ≈ 750,000 words ≈ 8 full novels in a single prompt.
